# Trade Journal Python

A Trade Journal application built using Python.

This project currently has:

* Terminal-based Trade Journal
* GUI-based Trade Journal using Tkinter

## Features

### Terminal Version

* Add trades
* Modify trades
* Delete trades
* Search by Trade ID
* Win rate calculation
* Best/Worst trade
* Total P/L calculation
* JSON database persistence

### GUI Version

* GUI inputs using Tkinter
* Profit/Loss calculation
* Trade display box
* JSON save/load
* Input validation
* Dynamic GUI updates
* Total P/L display
